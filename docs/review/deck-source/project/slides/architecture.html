ADR-005 · 010–012 · Bounded

Rail and registry are simulators; only the green pot moves money, through the ledger.

Full C4 views: docs/architecture/02 · Themes: docs 16–18

Speaker B (Taha). Modular monolith on purpose: one consistency boundary, one team, one semester. The ledger is the only financial truth; the rail is truth only for what it did, and it lives in a separate schema so reconciliation is meaningful. RailPort lets a licensed sandbox replace the simulator without touching payments. The three themes we built plug into the same controls: onboarding referrals go to Compliance, chat handoffs go to Ops, and neither of those can move money. The green pot moves the customer’s own money only as one balanced, idempotent journal from 2100 to 2110, and an offset is just a normal Raast payment.
