Live map in Mission Control, captured during a real settlement

Speaker B (Taha). This is our live map in Mission Control, captured as a payment settled: the green path is the payment moving from the phone, through the checks, into the ledger, out to Raast and back. Three ideas. First, the ledger is the only source of truth about money; screens read it but never change it. Second, there is only one payment path: a bill, a top-up or a green offset is just a normal payment, so it gets every safety check. Third, Raast is simulated and kept in its own space, so reconciliation compares two separate records. We built it as one well-structured app on purpose: one team, one semester, one place where money is kept consistent.
