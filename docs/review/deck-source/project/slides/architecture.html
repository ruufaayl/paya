ADR-005 · 010 · 011 · Bounded

Rail and registry are simulators; the themes move no money.

Full C4 views: docs/architecture/02 · Themes: docs 16–17

Speaker B (Taha). Modular monolith on purpose: one consistency boundary, one team, one semester. The ledger is the only financial truth; the rail is truth only for what it did, and it lives in a separate schema so reconciliation is meaningful. RailPort lets a licensed sandbox replace the simulator without touching payments. The two themes we built, digital onboarding and conversational banking, plug into the same controls: referrals go to Compliance, chat handoffs go to Ops, and neither can move money.
