Neither the triage agent nor the Paya Assistant can move money: tests read their source. The assistant answers from the customer’s own ledger, in English or Roman Urdu, and redacts secrets.

ADR-008 · ADR-011 · evidence/ai/evaluation.md · tests C1–C10

Speaker C (Harris). Reconciliation triage was chosen because a wrong suggestion costs time, not money. It abstains under 0.75 confidence, above PKR 100k or with a compliance link, and only the case owner can accept or override. The Paya Assistant is the customer-facing side: deterministic intents over read-only, customer-scoped tools, so there is nothing to prompt-inject. “Send money” returns a link into the normal review-and-authorise flow. Card numbers, CNICs and OTPs are removed before anything is stored, and “talk to a person” opens an audited case. AI is never used on identity decisions.
